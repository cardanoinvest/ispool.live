# Static GitHub Pages redesign

Upload the included index.html and 404.html into your existing publishing folder, replacing those files. No backend, npm install, build or Actions changes are required. Keep your current domain configuration, robots.txt, sitemap.xml and existing favicon/OG image assets.

index.html is self-contained HTML/CSS/JavaScript. It retains the original browser-side Blockfrost configuration and API key as requested. Browser requests still depend on that key being valid, API quota, and any origin restrictions allowing your actual website origin. The key remains publicly visible; this redesign does not secure it.

Design: navy/gold palette, dashboard hero, improved typography, compact metric cards, clearer pool ID controls, cleaner performance panel, mobile layout and accessible focus states. All four languages, copy ID, QR and delegation dialogs retained. Incorrect annualized ROA replaced with latest-epoch block count; history summary now labels displayed epochs accurately. No invented live data.

Original uploaded files are unchanged. The live website was not modified. Syntax and static structure checked. Browser rendering and live API integration were not verified in this environment. Referenced image assets were not supplied and are not bundled. This is designed for your existing ispool.live custom domain; canonical and sitemap domain values remain unchanged.
